# Política de Privacidade — FlashLingo

**Última atualização:** 5 de outubro de 2026

## 1. Informações que Coletamos

O FlashLingo **não coleta, armazena ou transmite** dados pessoais para servidores externos. Todos os dados permanecem exclusivamente no seu dispositivo.

### Dados armazenados localmente:
- **Palavras adicionadas:** palavra em inglês, tradução, pronúncia fonética, classe gramatical, exemplos, tags e progresso SRS (nível, próxima revisão, fator de facilidade)
- **Estatísticas de estudo:** total de revisões, acertos, sequência de dias, atividade diária
- **Áudio em cache:** arquivos de pronúncia baixados da Wikimedia Commons, armazenados temporariamente no dispositivo

## 2. Como Usamos os Dados

Todos os dados são usados exclusivamente para:
- Fornecer a funcionalidade de flashcards com repetição espaçada (SRS)
- Exibir estatísticas de progresso pessoal
- Tocar pronúncias de palavras (com cache local para uso offline)
- Enviar notificações locais de lembrete de estudo (opcional, requer permissão)

## 3. Compartilhamento de Dados

**Não compartilhamos dados com terceiros.** O app não possui:
- Contas de usuário ou login
- Analytics ou rastreamento
- Publicidade
- Conexão com redes sociais
- Servidor backend próprio

A única comunicação externa é com a API pública da **Wikimedia Commons** para buscar áudios de pronúncia e com a **Wiktionary** para buscar transcrições fonéticas. Essas requisições não enviam dados pessoais — apenas o nome da palavra buscada.

## 4. Permissões do App

| Permissão | Finalidade | Obrigatória? |
|-----------|-----------|-------------|
| Notificações | Lembrete diário de estudo | Não (opcional) |
| Armazenamento | Cache de áudio e banco de dados local | Sim (automático) |
| Internet | Buscar pronúncias nativas | Não (app funciona offline após primeiro uso) |

## 5. Segurança dos Dados

- Todos os dados ficam no armazenamento local do dispositivo (SQLite)
- Nenhum dado é transmitido para servidores externos
- Áudios em cache podem ser limpos a qualquer momento pelo usuário
- A desinstalação do app remove todos os dados permanentemente

## 6. Direitos do Usuário

Como todos os dados são locais, você tem controle total:
- **Acessar:** todos os dados são visíveis nas telas do app
- **Excluir:** exclua palavras individualmente ou desinstale o app para remover tudo
- **Exportar:** funcionalidade planejada para versões futuras

## 7. Crianças

O FlashLingo não é direcionado a crianças menores de 13 anos. Não coletamos dados de ninguém, independentemente da idade.

## 8. Alterações nesta Política

Atualizações serão publicadas nesta página com a data de revisão.
